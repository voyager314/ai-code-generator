# Wise Code Frontend

基于 React + TypeScript + Vite + Tailwind CSS 构建的前端应用。

## 启动开发

```bash
# 安装依赖
npm install

# 启动开发服务器（会自动代理到 localhost:8081/api）
npm run dev

# 构建生产版本（输出到 ../src/main/resources/static/）
npm run build
```

## 功能模块

- 登录/注册
- 应用列表（我的应用 + 精选应用）
- AI 对话生成（支持深度思考模式）
- 应用部署和下载
- 管理员后台（用户管理）

## 技术栈

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Zustand（状态管理）
- React Router
- Axios
